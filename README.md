# Juanita du Preez

Co-creator and Lead Engineer of [Axlo](https://axlo.vercel.app) by SyncTech, a multi-tenant platform for car rental and fleet companies. I have been its only maintainer since September 2026. Open to full-time and contract work, fully remote.

Axlo's code is private, so my commits show here only as private contributions. You can try the product instead:

- [Live demo](https://axlo.vercel.app/demo): sign in as a rental or fleet admin, staff member or customer. The data resets daily.
- [Portfolio](https://axlo.vercel.app/portfolio/juanita-du-preez): the roles I held and the work behind them.

## What I work on

- **Frontend:** one React application with four front ends, 94 pages and a design system of 29 components. 20 pages score 100 for accessibility in Lighthouse.
- **Backend:** NestJS and PostgreSQL modules for compliance tracking, drivers, vehicle alerts, data import and report calculations.
- **Testing:** 258 end-to-end tests that run on every push.
- **Releases:** the CI/CD pipeline, Docker images, error tracking and backups. A deploy needs a green CI run and rolls back if the new version is unhealthy.
- **Languages:** about 4,200 interface strings in seven languages, kept in step with the code by a CI check.
